# Codepen

Карточка Codepen с плавной анимацией и современным темным оформлением.

## Особенности

- Используются CSS-переменные для легкой настройки стилей.
- Плавная анимация появления карточки.
- При наведении на карточку блок статистики (`card-stats`) плавно выезжает вниз
  на темном фоне.
- Современный дизайн с использованием шрифта
  [Karla](https://fonts.google.com/specimen/Karla).

## Структура

- **index.html** — разметка карточки.
- **style.css** — стилизация карточки с комментариями и переменными.
- **images/** — изображения для превью и аватара.

## Как использовать

1. Откройте `index.html` в браузере.
2. При наведении на карточку появится блок статистики с анимацией.

## Кастомизация

- Изменяйте значения CSS-переменных в начале файла `style.css` для быстрой
  настройки внешнего вида.
- Для замены изображений используйте свои файлы в папке `images`.
